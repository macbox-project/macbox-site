# ClassicBox

A DOSBox for classic Mac software.

ClassicBox runs period Macintosh applications and games in a browser or on your
desktop, without a ROM image and without hunting down an emulator configuration.
It is built on [Executor](https://github.com/johnballentine/classicbox), a native
reimplementation of the Macintosh Toolbox and OS.
