Mac OS 9 compatibility layer

Classic Mac software, running like any other app.

MacBox is not a virtual machine. Like Wine does for Windows programs, it runs Mac OS 9 software directly on your desktop — no boot screen, no emulated screen to live inside. Open a classic app and it appears in its own window, next to everything else you have running.
